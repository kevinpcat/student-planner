# student-planner
We are creating a college planner for students, aiming to make college life easy with everything all together.

- Plan for now.

*General planner - Enter modules, assignments and deadlines. Calculate workload (include how long) and recommend which task to work on first.

*Student grade calculator - Track assesments, calculated weighted grades and determine what mark is needed in the final exam.

*Personal library manager - Catalogue books, track reading progress, search by author or category, and generate reading statistics.

- Potential additional ideas

*Game that helps you study for example: gives definition or word and you have to match with the correlating word - Kevin

*Quizzes for each modules - created of information from books (obj). - Muthu
